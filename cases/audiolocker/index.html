AudioLocker

Utilitário leve para controle e limitação de volume no Windows

Baixar Última Versão (GitHub)

O que é o AudioLocker?

O AudioLocker é uma aplicação para Windows desenvolvida para manter o volume do áudio do computador sempre dentro de um limite máximo definido, protegida por senha de administrador. É ideal para ambientes compartilhados, como bibliotecas, escolas ou escritórios.

Como Baixar e Instalar

  1. Acesse a página de lançamentos no GitHub e baixe o executável AudioLocker.exe localizado na seção Assets:
  2. Não é necessária instalação. Basta dar dois cliques no arquivo baixado para executá-lo.

Como Usar

  1. Primeira Execução: Ao abrir o aplicativo pela primeira vez, uma janela solicitará a criação de uma Senha de Administrador, o Volume Máximo (%) e o tempo padrão para desbloqueios:
  2. Execução em Segundo Plano: O app rodará na barra de tarefas (ao lado do relógio do Windows). O ícone permanecerá vermelho enquanto o áudio estiver restrito.
  3. Desbloquear o Som: Clique com o botão direito no ícone da bandeja, escolha Desbloquear Áudio e digite sua senha. O ícone ficará verde durante o período liberado.
  4. Encerrar o App: Clique com o botão direito no ícone da bandeja, selecione Sair e confirme a senha.
Requisito do Sistema: Certifique-se de ter ao menos um dispositivo de saída de áudio habilitado no Windows antes de iniciar o aplicativo.
